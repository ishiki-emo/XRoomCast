# 配信者ガイド — はじめてでも大丈夫

XRoomCast で配信したい人向けのガイドです。プログラミングの知識は要りません。
難しい作業はセットアップウィザードが代わりにやります。

> 開発者向けの詳しい構築手順は [SETUP.md](../SETUP.md)、仕組みの説明は
> [アーキテクチャ.md](アーキテクチャ.md) にあります。このガイドだけで配信までいけます。

---

## 1. これは何?

あなたのアバターの「動き」だけをインターネットに流す配信システムです。
視聴者は**URLを開くだけ**。アプリのインストールも会員登録も要りません。
スマホならARで机の上に、Quest等のHMDなら等身大で、あなたのアバターが現れます。

動画を送らないので、通信量は動画配信の**100分の1以下**です。

## 2. 「Cloudflareが必要」って、こわくない?

こわくないです。**ホームページスペースを借りる感覚に毛が生えた程度**だと思ってください。

- **Cloudflareは世界最大手のインターネットインフラ会社**です。世界中のWebサイトの
  かなりの部分がここを経由しています。怪しい業者ではありません
- 借りると言っても**月額固定費はゼロ**。使った分だけの従量制で、しかも
  **無料枠がとても大きい**ので、個人配信の規模ではほぼ0円で収まります
- **クレジットカードの登録は必要**です。アバターファイルの置き場(R2という機能)を
  使うのに登録が求められるためです。**登録しただけでは1円もかかりません**

### どのくらい無料なの?

無料枠は「延べ視聴者数 × 時間」で**月に約17,000人時間**ぶんあります(音声込み)。

| 使い方の例 | 月の利用 | 料金 |
|---|---|---|
| 身内でテスト(3人・2時間) | 1回 | **0円** |
| 週1配信(20人・2時間) | 4回 | **0円** |
| 週2配信(50人・2時間) | 8回 | **0円** |
| 単発イベント(200人・3時間) | 1回 | **0円** |
| 毎日配信(100人・3時間) | 30回 | **0円**(無料枠の約半分) |

無料枠を超えても、**視聴者1人が1時間観て約0.4円**です。
詳しい内訳が気になる人は Cloudflare のダッシュボードでいつでも実測を見られます。

### それでも心配な人への「2つの保険」

1. **同時に見られる人数の上限を設定する**(配信者コンソールの「⚙️ ルーム設定」)。
   視聴URLが想定外に拡散しても、この上限より課金は伸びません。**必ず設定してください**
2. **支出アラートを設定する**。Cloudflareダッシュボード → 通知(Notifications)で
   「請求額が○ドルを超えたらメール」を作れます。0円運用のつもりなら $1 で
   仕掛けておけば、想定外に気づけます

### Cloudflareなしでは配信できないの?

自分のPCの中だけで動かすことはできます(練習・動作確認に便利)。ただし
**スマホやHMDのAR/VRで見てもらうにはCloudflareが必須**です。
ブラウザのセキュリティ仕様(ARはHTTPSのページでしか動かない)によるもので、
回避はできません。「人に見てもらう配信」をするなら最初からCloudflare前提で考えてください。

## 3. 最初の準備(1回だけ・30分くらい)

1. **Cloudflareアカウントを作る** — [登録ページ](https://dash.cloudflare.com/sign-up)で
   メールアドレスとパスワードを決めるだけ
2. **R2を有効化する** — ダッシュボードの「R2」を開くと案内が出ます。
   ここでカードを登録します(登録だけ。課金はされません)
3. **`セットアップ.bat` をダブルクリック** — ブラウザにウィザードが開きます。
   あとは画面に沿って進むだけで、あなた専用の配信環境ができあがります。
   最後に**視聴URL**(視聴者に配る)と**配信者URL**(あなただけの秘密)が表示されます

> 配信者URLは合鍵です。**人に渡さない・配信画面に映さない**ように注意してください。

## 4. 配信のしかた

### PCから配信する(VSeeFace等を使う)

1. VSeeFace等のトラッキングソフトでアバターを動かせる状態にする
2. VSeeFaceの設定で **OSC/VMC送信を有効化**(送信先 `127.0.0.1`、ポート `39539`)
3. **`配信開始.bat` をダブルクリック**(配信の中継が始まります。窓は開いたまま)
4. ブラウザで**配信者URL**を開くと、視聴者に届いている姿を確認できます

やめるときは `配信開始.bat` の窓を閉じ、コンソールの**「退室する」**を押します。

### HMD(Quest等)から配信する — PCもVSeeFaceも不要

1. HMDのブラウザで**配信者URL**を開く。PCで配信者URLを開いているなら、「🥽 Questでこのページを開く」の
   **QRを大きく表示**して、QuestのQR読み取りで読むのが楽です(QRは配信を操作できる鍵なので、人に見せないこと)
2. 「🥽 パススルーで配信」または「🌌 VRで配信」を押す
3. 正面を向いた状態で入る(その瞬間の立ち位置が基準になります)

マイクも自動でONになります。終了はHMD内の操作パネルからできます。

### 配信者コンソール(配信者URLのページ)でできること

| ボタン・欄 | できること |
|---|---|
| 🔗 視聴URL | 視聴者に配るURLとQRコード。QRは会場掲示用に全画面表示できます |
| ⚙️ ルーム設定 | 誰でも見られる/招待制、コメント可否、**人数上限**、緊急停止 |
| アバター | VRMのアップロード・切り替え(視聴者全員に自動で反映) |
| マイク配信 | 声を流す(アバターの位置から聞こえ、口も動きます) |
| 鏡(プレビュー) | 視聴者に見えている姿の確認 |
| 退室する | 席を片付けて配信を終える |

## 5. イベント会場で使う

1. ルーム設定を「誰でも / 視聴者の位置=全員に見せる / **人数上限=会場の規模**」にする
2. 視聴URLの**QRを「大きく表示」**して会場のモニタに映すか、印刷して掲示する
3. 参加者はスマホでQRを読むだけ。**インストールも登録も不要**です
4. 終わったら**緊急停止**を押し、マイクと配信(bat または HMD)も止める

事前チェック: 使うVRMをアップロードして表示確認/**QRを実機で読んで**視聴できるか確認/
iPhoneの人にはAR用に [EyeJack X](https://play.eyejack.xyz/) を案内(そのままでも3D表示は可)。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 音が聞こえないと言われた | 視聴側で一度画面をタップしてもらう(「🔇 タップで音声ON」)。ブラウザの仕様です |
| ARボタンが出ないと言われた | iPhone/iPadはそのままではARになりません(3D表示は可)。EyeJack X を案内 |
| アバターが動かない | `配信開始.bat` の窓が開いているか、VSeeFaceのVMC送信がONか確認 |
| アバターの顔が消える(HMD) | シェイプキーの多すぎるVRMで起きがち。軽いモデルを使う |
| もっと詳しく | [SETUP.md](../SETUP.md) の「うまくいかないとき」へ |

## 7. お金についてもう少しだけ

- 課金の中心は「視聴者への転送量」です。**配信者側が何時間流しても、
  視聴者がいなければほぼゼロ**です
- **マイクを使わなければ転送量は約1/3**になります(無料枠が心配な大型イベント向けの技)
- アップロードしたVRMは置きっぱなしだと保管料の対象になります(無料枠10GB)。
  イベント後はコンソールから削除しておくときれいです
- 上限アラートと人数上限(§2の「2つの保険」)さえ入れておけば、
  「気づいたら高額請求」は起きない構造です
