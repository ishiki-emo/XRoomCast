# 配信者ガイド — はじめてでも大丈夫

XRoomCast で配信したい人向けのガイドです。プログラミングの知識は要りません。
難しい作業はセットアップウィザードが代わりにやります。

> 開発者向けの詳しい構築手順は [SETUP.md](../SETUP.md)、仕組みの説明は
> [アーキテクチャ.md](アーキテクチャ.md) にあります。このガイドだけで配信までいけます。

---

## 1. これは何?

あなたのアバターの「動き」だけをインターネットに流す配信システムです。
視聴者は**URLを開くだけ**。アプリのインストールも会員登録も要りません。
スマホならARで机の上に、Quest等のHMDなら等身大で、あなたのアバターが現れます。

動画を送らないので、通信量は動画配信の**100分の1以下**です。

## 2. 「Cloudflareが必要」って、こわくない?

こわくないです。**ホームページスペースを借りる感覚に毛が生えた程度**だと思ってください。

- **Cloudflareは世界最大手のインターネットインフラ会社**です。世界中のWebサイトの
  かなりの部分がここを経由しています。怪しい業者ではありません
- 借りると言っても**月額固定費はゼロ**。使った分だけの従量制で、しかも
  **無料枠がとても大きい**ので、個人配信の規模ではほぼ0円で収まります
- **クレジットカードの登録は必要**です。アバターファイルの置き場(R2という機能)を
  使うのに登録が求められるためです。**登録しただけでは1円もかかりません**

### どのくらい無料なの?

無料枠は「延べ視聴者数 × 時間」で**月に約17,000人時間**ぶんあります(音声込み)。

| 使い方の例 | 月の利用 | 料金 |
|---|---|---|
| 身内でテスト(3人・2時間) | 1回 | **0円** |
| 週1配信(20人・2時間) | 4回 | **0円** |
| 週2配信(50人・2時間) | 8回 | **0円** |
| 単発イベント(200人・3時間) | 1回 | **0円** |
| 毎日配信(100人・3時間) | 30回 | **0円**(無料枠の約半分) |

無料枠を超えても、**視聴者1人が1時間観て約0.4円**です。
詳しい内訳が気になる人は Cloudflare のダッシュボードでいつでも実測を見られます。

### それでも心配な人への「2つの保険」

1. **同時に見られる人数の上限を設定する**(配信者コンソールの「⚙️ ルーム設定」)。
   視聴URLが想定外に拡散しても、この上限より課金は伸びません。**必ず設定してください**
2. **支出アラートを設定する**。Cloudflareダッシュボード → 通知(Notifications)で
   「請求額が○ドルを超えたらメール」を作れます。0円運用のつもりなら $1 で
   仕掛けておけば、想定外に気づけます

### Cloudflareなしでは配信できないの?

自分のPCの中だけで動かすことはできます(練習・動作確認に便利)。ただし
**スマホやHMDのAR/VRで見てもらうにはCloudflareが必須**です。
ブラウザのセキュリティ仕様(ARはHTTPSのページでしか動かない)によるもので、
回避はできません。「人に見てもらう配信」をするなら最初からCloudflare前提で考えてください。

## 3. 最初の準備(1回だけ・30分くらい)

1. **Cloudflareアカウントを作る** — [登録ページ](https://dash.cloudflare.com/sign-up)で
   メールアドレスとパスワードを決めるだけ
2. **R2を有効化する** — ダッシュボードの「R2」を開くと案内が出ます。
   ここでカードを登録します(登録だけ。課金はされません)
3. **`セットアップ.bat` をダブルクリック** — ブラウザにウィザードが開きます。
   あとは画面に沿って進むだけで、あなた専用の配信環境ができあがります。
   最後に**視聴URL**(視聴者に配る)と**配信者URL**(あなただけの秘密)が表示されます

> 配信者URLは合鍵です。**人に渡さない・配信画面に映さない**ように注意してください。

## 4. 配信のしかた

### Webカメラだけで配信する — いちばん手軽(VSeeFaceもHMDも不要)

1. PCのブラウザ(Chrome / Edge 推奨)で**配信者URL**を開く
2. プレビューの下の「📷 Webカメラで配信」を押し、カメラとマイクの使用を許可する
3. カメラの正面を向く(開始したときの顔の向きが正面になります)

顔の向き・まばたき・口・笑顔がアバターに映ります。マイクも自動でONになります。
手は既定では下ろしたままです(下の「手も動かす」で変えられます)。

- **映像はどこにも送られません。** 動きの推定はPCのブラウザの中だけで行います
  (初回だけ、推定のモデルを数十MBダウンロードします)
- 正面がずれたら「正面を取り直す」を押してください
- やめるときは「⏹ Webカメラ配信を止める」を押し、コンソールの**「退室する」**を押します
- 精度はVSeeFaceやHMDより控えめです。手の細かい動き・横向きは苦手です

**「⚙ Webカメラの設定」でできること**(設定はこのブラウザにだけ保存されます。サーバーには送りません)

- **普通の顔を登録**: 無表情で正面を向いて3秒。人ごとの癖を差し引くので、まばたきや口の誤反応
  (意図しないウインクなど)が減ります。**最初に1回やっておくのがおすすめです**
- **表情の登録**: 「この顔をしたら、アバターのこの表情」を登録できます(例: 思いきり笑う → happy)。
  アバターが持っている表情から選べます。一覧の棒で、いまの顔がどれだけ近いかを確かめられます
- **滑らかさ**: 「反応が速い ↔ 滑らか」を調整できます
- **手も動かす**: 既定はオフです(カメラ1台では手の奥行きが取れず暴れやすいため)。オンにすると手も推定します
- **書き出し・読み込み**: 登録した表情を、別のPCへ持っていけます

手までしっかり動かしたいときは、VSeeFace等(PCから配信)か、HMDから配信してください

### PCから配信する(VSeeFace等を使う)

1. VSeeFace等のトラッキングソフトでアバターを動かせる状態にする
2. VSeeFaceの設定で **OSC/VMC送信を有効化**(送信先 `127.0.0.1`、ポート `39539`)
3. **`配信開始.bat` をダブルクリック**(配信の中継が始まります。窓は開いたまま)
4. ブラウザで**配信者URL**を開くと、視聴者に届いている姿を確認できます

やめるときは `配信開始.bat` の窓を閉じ、コンソールの**「退室する」**を押します。

### HMD(Quest等)から配信する — PCもVSeeFaceも不要

1. HMDのブラウザで**配信者URL**を開く。PCで配信者URLを開いているなら、「🔗 共有」タブの
   **配信者URLのQRを大きく表示**して、QuestのQR読み取りで読むのが楽です(QRは配信を操作できる鍵なので、人に見せないこと)
2. 「🥽 パススルーで入る」または「🌌 VRで入る」を押す
3. 正面を向いた状態で入る(その瞬間の立ち位置が基準になります)

VRに入っただけでは配信されません。HMD内の操作パネル(メニュー)の**「配信を開始」**で、動きとマイクの配信が始まります
(「配信を停止」で止まります)。終了も操作パネルからできます。

- **メニューは手に載せて使います**(VRChat のクイックメニューと同じ)。VRに入ると、まず左手の上に開きます
  - コントローラ: **B/Y ボタン**を押した手の上に開きます。同じ手でもう一度押すと閉じ、反対の手で押すとそちらへ移ります
  - 素手: **手のひらを顔に向ける**と、その手の上に開きます。手のひらを返すと閉じます
  - 選ぶのは反対の手です(ビームを当ててトリガー、素手ならつまむ)
  - 中身はタブに分かれています: 配信(配信・マイク・VRの終了) / 視点 / 表情 / 体(位置合わせ・姿勢・身長・目線) / 手首
- **マイクのミュートと復帰は、左スティックの押し込み**でもできます(メニューを開かずに)。
  切り替わると左のコントローラが震えます(オンで1回、オフで2回)

- 右スティックを左右に倒すと、30°ずつ向きを変えられます(アバターもその向きを向きます)
- 立ち位置を取り直すときは、操作パネルの「位置を合わせ直す」を押します
- **立って遊ぶか、座って遊ぶか**を、操作パネルの「姿勢」で選べます(VRChat の立ちモード・座りモードと同じ)。
  - **立って遊ぶ**(既定): 立ったまま入ってください(位置合わせのときの目の高さで身長を合わせます)。しゃがむ・前かがみもそのまま映ります
  - **座って遊ぶ**: 座ったままでも、アバターは立った姿勢になります。途中で立ち上がるとアバターは浮くので、立つなら「立って遊ぶ」に切り替えてください
  - 切り替えると、3秒数えてから位置を合わせ直します。その間に楽な姿勢で正面を向いてください
    (パネルを押すときの前かがみのまま合わせると、座り直したときにアバターが浮きます)
- **身長と目線**(配信者コンソールの「📏 身長と目線」、またはHMD内パネルの「身長」「目線」):
  - **リアルの身長を選ぶ**と、立っていても座っていても、毎回同じ大きさの感覚になります(ヘッドセットの床の高さが正しい前提)。
    床がずれていそうなときは、位置合わせのときに知らせます
  - **自動**(既定)は、位置合わせのときの目の高さから合わせます。床の高さがずれている環境ではこちらが接地しやすいです
  - **目線の高さ**は、OVR Advanced Settings の空間の高さのオフセットと同じです。大きさは変えずに、自分の位置ごと上下にずらします
    (下げるとアバターの頭ごと下がって膝が曲がり、上げると浮きます)。その場で効きます
- **VRに入るとすぐ、自分のアバターに入った状態になります**(VRChat と同じ。下を向くと自分の体が見え、手がコントローラに重なります)。
  操作パネルの「視点」で切り替えられます:
  - **自分に入る**(既定)
  - **自分＋鏡**: 自分に入ったまま、右前方の姿見に自分の姿が映ります(VRChat の鏡と同じ)。鏡は処理が重いので、Quest 単体で重いときは消してください
  - **アバターを前に**: 右前方にアバターを立たせて、視聴者から見た自分を確かめます
  - **隠す**
  配信を始める前から、自分の動きでアバターが動きます

コントローラを置いて**素手でも配信できます**(指の動きもアバターに映ります)。
素手のときに位置がずれたら、操作パネルの「位置を合わせ直す」を押してください。

Questなら、入るときに体の動きの使用を許可すると、しゃがむ・体をひねるといった動きもアバターに映ります。

**ハンドジェスチャーと表情(VRChat と同じ)**

コントローラの握り方で、VRChat と同じ7種類のハンドジェスチャー(グー・パー・指差し・ピース・ロック・指鉄砲・いいね)になり、
手の形と表情が切り替わります。素手でも、指の形から同じジェスチャーを読み取ります。

- どのジェスチャーでどの表情にするかは、配信者コンソールの「🖐 ジェスチャーと表情」で、左右の手それぞれに選べます
  (既定: パー=驚き、ピース=喜び、ロック=怒り、いいね=楽しい)。**HMDのブラウザで配信するなら、HMDのブラウザで設定してください**
  (設定はその端末のブラウザに保存されます)
- グーの表情は、トリガーの引き具合で強さが変わります
- HMD内の操作パネルの「表情」で選ぶと、その表情に固定できます(「手で切替」でジェスチャーに戻ります)

### PCVR(Virtual Desktop・SteamVR・Quest Link など)から配信する

PCにつないだヘッドセットでも配信できます。

1. ヘッドセットをPCにつなぎ、VRの状態にしておく(Virtual Desktop で接続する、SteamVR を起動する など)
2. **PCの Chrome または Edge** で**配信者URL**を開く(VRの中に浮かぶPCの画面から操作して大丈夫です)
3. 「🌌 VRで入る」を押して正面を向き、HMD内の操作パネルの「配信を開始」を押す

- **パススルー(🥽)は使えません。** PCのブラウザは現実の映像を重ねられないため、VRで配信します
- **SteamVR の中のブラウザでは入れません。** PCの Chrome / Edge を使ってください
- 頭と両手のコントローラが動きます。Vive トラッカー等のフルトラッキングは使えません(腰や足は自動で推定されます)
- 手首の向きがずれるときは、配信者コンソールの「手首の向き」で調整してください

**「🌌 VRで入る」が出ない・押しても入れないとき**

1. Chrome のアドレスバーに `chrome://flags` と入れ、「WebXR」で検索。**「Force WebXR Runtime」を「OpenXR」**にして、Chromeを再起動する
   (Virtual Desktop で入れなかったときは、これで直りました)
2. それでも駄目なら、Windows の OpenXR の既定のランタイムを確かめる。
   Virtual Desktop なら Streamer の設定で VDXR、SteamVR なら SteamVR の設定 →「OpenXR」→「SteamVR を OpenXR ランタイムとして設定」
3. 切り分けたいときは、公式のサンプル(https://immersive-web.github.io/webxr-samples/immersive-vr-session.html)で「Enter VR」できるか試す。
   サンプルでも入れなければPC側の設定、サンプルでは入れるなら XRoomCast 側の問題です

### 配信者コンソール(配信者URLのページ)でできること

PCの広い画面では、左にマイク配信とプレビュー(スクロールしても残ります)、右に設定のタブが並びます。
狭い画面では縦一列になります。各欄の詳しい説明は「ⓘ」を押すと開きます。

| ボタン・欄 | できること |
|---|---|
| 🔗 共有(タブ) | 視聴者に配るURLとQRコード(会場掲示用に全画面表示できます)、Quest用の配信者URLのQR |
| ⚙️ ルーム設定(タブ) | 誰でも見られる/招待制、コメント可否(**既定はオフ**)、**人数上限**、緊急停止、視聴者の位置の見せ方 |
| 🎪 ステージ(タブ) | 背景モデル(GLB)の切り替え、空と地面の色 |
| 🧍 アバター(タブ) | VRMのアップロード・切り替え(視聴者全員に自動で反映) |
| マイク配信 | 声を流す(アバターの位置から聞こえ、口も動きます) |
| 鏡(プレビュー) | 視聴者に見えている姿の確認 |
| 退室する | 席を片付けて配信を終える |

## 5. イベント会場で使う

1. ルーム設定を「誰でも / 視聴者の位置=全員に見せる / **人数上限=会場の規模**」にする
2. 視聴URLの**QRを「大きく表示」**して会場のモニタに映すか、印刷して掲示する
3. 参加者はスマホでQRを読むだけ。**インストールも登録も不要**です
4. 終わったら**緊急停止**を押し、マイクと配信(bat または HMD)も止める

事前チェック: 使うVRMをアップロードして表示確認/**QRを実機で読んで**視聴できるか確認/
iPhoneの人にはAR用に [EyeJack X](https://play.eyejack.xyz/) を案内(そのままでも3D表示は可)。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| 音が聞こえないと言われた | 視聴側で一度画面をタップしてもらう(「🔇 タップで音声ON」)。ブラウザの仕様です |
| ARボタンが出ないと言われた | iPhone/iPadはそのままではARになりません(3D表示は可)。EyeJack X を案内 |
| アバターが動かない | `配信開始.bat` の窓が開いているか、VSeeFaceのVMC送信がONか確認 |
| アバターの顔が消える(HMD) | シェイプキーの多すぎるVRMで起きがち。軽いモデルを使う |
| PCVRで「VRで入る」が出ない・入れない | Chrome の `chrome://flags` で「Force WebXR Runtime」を OpenXR に(4章「PCVRから配信する」) |
| もっと詳しく | [SETUP.md](../SETUP.md) の「うまくいかないとき」へ |

## 7. お金についてもう少しだけ

- 課金の中心は「視聴者への転送量」です。**配信者側が何時間流しても、
  視聴者がいなければほぼゼロ**です
- **マイクを使わなければ転送量は約1/3**になります(無料枠が心配な大型イベント向けの技)
- アップロードしたVRMは置きっぱなしだと保管料の対象になります(無料枠10GB)。
  イベント後はコンソールから削除しておくときれいです
- 上限アラートと人数上限(§2の「2つの保険」)さえ入れておけば、
  「気づいたら高額請求」は起きない構造です
