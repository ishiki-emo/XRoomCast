XRoomCast セットアップ

Cloudflare上にあなた専用の配信環境を作ります。所要 約10分(ほとんどは自動)。

✅ セットアップ済みの環境が見つかりました

設定を作り直したい場合・デプロイをやり直したい場合は、このまま下のステップを進めてください。 発行済みのキーは再利用されるので、URLは変わりません。

⚠️ 手動で構築された設定(wrangler.jsonc)が見つかりました

このウィザードを最後まで実行すると apps/viewer/wrangler.jsonc と Workerのシークレットが上書きされ、既存の視聴URL・配信者URLは使えなくなります。

1Cloudflareにログイン

ボタンを押すとブラウザにCloudflareの認証ページが開きます。 「Allow」を押したら、そのタブは閉じてこのページへ戻ってきてください。 完了は自動で検知します。

Cloudflareのアカウントをまだ持っていない場合は、先に アカウント作成 を済ませてください(無料。ただしR2の利用にクレジットカード登録が必要です)。

アカウントが複数あります。使うアカウントを選んでください:

2Realtime Appを作って貼り付け

モーションと音声の中継に使う「Realtime App」をダッシュボードで作成します (ここだけ手作業が必要です)。

  1. Realtimeのページを開く(別タブで開きます)
  2. 「Create App」を押して、名前は自由に付ける(例: xroomcast)
  3. 表示された App ID と App Secret を下へコピーする

3アバター(VRM)を選ぶ

最初に表示するVRMファイルを選んでください。 あとから配信者コンソールで追加・切り替えできるので、まず1体でOKです。

軽いモデルほど視聴者の読み込みが速くなります(目安 10〜20MB)。上限は80MBです。

4セットアップを実行

ここから先は全部自動です。ビルドとアップロードで数分かかります。 終わるまでこのページを開いたままにしてください。
